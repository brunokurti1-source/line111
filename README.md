# LINE111

Bilingual (SQ/EN) sportsbook demo + casino odds **provider** API surface for Project bet111.

Bruno Kurti sells LINE111 contracts to casinos — this app is a white-label-friendly live board plus sample integrator docs. Odds are generated locally via a consensus engine (fair probability → margin → calibrate to public sample). No third-party odds API keys. No scraping.

## Run

```bash
npm install
npm run dev
```

## Stack

Vite · React · TypeScript
